Compra tu propia etiqueta NFC

Blank funciona con etiquetas NFC estándar. No necesitas una pieza especial: basta con una etiqueta NFC compatible con tu móvil Android. El producto enlazado aparece publicado como NTAG215.

Qué recomendamos

  • Etiquetas NFC adhesivas o tipo tarjeta.
  • Formato NTAG o equivalente compatible con Android.
  • Una etiqueta que puedas dejar lejos del móvil cuando quieras bloquear distracciones.
